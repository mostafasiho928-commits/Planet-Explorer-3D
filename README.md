# مَدار — مستكشف الكواكب (المرحلة الرابعة المحسّنة)

لعبة استكشاف ثلاثية الأبعاد للمتصفح، مبنية على Three.js r128. يعمل المشروع من صفحة HTML مع ملف تعريف PWA وأيقونة، ولا يحتاج إلى Node.js أو خطوة بناء.

## المراحل المنجزة

### المرحلة الأولى — نواة الاستكشاف
- مشهد ثلاثي الأبعاد ورائد فضاء متحرك.
- حركة وقفز وجاذبية وكاميرا منظور شخص ثالث.
- عصا لمس للهاتف وأزرار لوحة المفاتيح.

### المرحلة الثانية — مولّد الكواكب
- 150,000,000 كوكب مرقّم.
- توليد حتمي لاسم كل كوكب وبيئته ومناخه وحرارته وجاذبيته وطول يومه وخصائصه.
- ثمانية أنماط بيئية مختلفة.
- بوابة لاختيار كوكب برقم أو اكتشاف كوكب عشوائي.

### المرحلة الثالثة — العوالم الكروية
- كوكب كروي بتضاريس إجرائية ثلاثية الأبعاد.
- قارات كبيرة متصلة ومحيطات واسعة، مع مناطق شاطئية على خطوط الساحل.
- موضع هبوط قريب من الساحل، وتوجيه الكاميرا نحو البحر عند وجود محيط.
- محيط بخامة أمواج متحركة، وغلاف جوي يتغير لونه وشفافيته.
- حركة اللاعب على سطح منحنٍ، وجاذبية وقفز بحسب اتجاه السطح.

### المرحلة الرابعة — الأنظمة البيئية والموارد
- غابات بأشجار أكبر متعددة الطبقات، مع اختلاف الكثافة والألوان حسب المنطقة الحيوية.
- غطاء عشبي وصخور موزعة إجرائياً حول منطقة الهبوط.
- غيوم منخفضة متحركة قرب الأفق لإضافة عمق بصري.
- بلورات معدنية كبيرة ومضيئة، مع مجموعة أولية مضمونة بالقرب من نقطة الهبوط.
- ماسح يحدد أقرب بلورة ويعرض بعدها واتجاهها، مع مؤشر مرئي فوق البلورة المختارة.
- زر «جمع» يظهر تلقائياً عند الاقتراب، أو استخدم المفتاح **F** على الكمبيوتر. استخدم زر المسح أو المفتاح **E** لتحديد بلورة.
- عدّاد مخزون البلورات.
- استخدام Instanced Mesh لتقليل عدد عمليات الرسم، مع جودة رسومية وظلال متوازنة للهواتف.

## جودة الرسوميات والأداء
- إعادة رفع دقة سطح الكوكب إلى 160×80 قطاعاً في الإعداد العادي، مع إعداد أخف للأجهزة محدودة الموارد.
- تفعيل الظلال على الهاتف والكمبيوتر؛ دقة خريطة الظلال 1024 للهاتف و2048 للأجهزة المكتبية.
- استخدام تنعيم الحواف ورفع حد دقة الرسم على الهواتف المتوسطة.
- إنشاء التضاريس والموارد على دفعات للسماح للمتصفح بتحديث الواجهة أثناء التحميل.

## الاتجاه الأفقي والهاتف
- تطلب اللعبة ملء الشاشة وتحاول قفل الاتجاه أفقياً عند الضغط على «ابدأ».
- ملف manifest.webmanifest يحدد orientation: landscape وdisplay: fullscreen.
- فتح index.html من ملف ZIP لا يفعّل إعدادات PWA. لتجربة قفل الاتجاه الحقيقي، افتح نسخة GitHub Pages عبر HTTPS، ثم من قائمة Chrome اختر «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية» وافتح اللعبة من أيقونتها.

## التحكم
- الكمبيوتر: W A S D أو الأسهم للحركة، Space للقفز، E للبحث عن البلورات، F لجمع البلورة المحددة.
- الهاتف: العصا الافتراضية للحركة، الزر ↑ للقفز، زر المسح لتحديد البلورة، وزر «جمع» الذي يظهر عند الاقتراب.
- اسحب على مساحة العالم لتدوير الكاميرا.
- زر «اختيار كوكب» يتيح الانتقال إلى كوكب آخر.

## ما لم يُنفذ بعد
لم تُنفذ بعد الكهوف والتعدين داخل الصخور، والأدوات والأسلحة، والطقس التفصيلي المتغير، والأقمار والحلقات، والمركبات الفضائية والهبوط والإقلاع، والمهام أو نظام البقاء.

## النشر
المستودع يستخدم GitHub Actions لنشر الموقع على GitHub Pages عند الدفع إلى الفرع main. يجب ضبط Settings → Pages → Build and deployment → Source: GitHub Actions.
