# مَدار — مستكشف الكواكب (المرحلة الأولى)

نموذج أولي للمرحلة الأولى من لعبة استكشاف كواكب ثلاثية الأبعاد. المشروع حالياً صفحة HTML واحدة تستخدم Three.js r128 من cdnjs، ولا يحتاج إلى Node.js أو خطوة بناء.

## ما يتضمنه النموذج

- مشهد ثلاثي الأبعاد مع سماء متدرجة وشمس وإضاءة اتجاهية وضوء سماوي.
- تضاريس إجرائية متصلة باستخدام Value Noise وFBM ودالة ارتفاع واحدة `heightAt(x, z)`.
- تحميل قطع التضاريس حول اللاعب وإعادة بنائها عند الانتقال بين القطع.
- رائد فضاء مبني من مجسمات هندسية بسيطة مع حركة للأطراف أثناء المشي.
- كاميرا منظور شخص ثالث تدور 360 درجة أفقياً وتتحكم بزاوية ارتفاعها.
- حركة نسبية لاتجاه الكاميرا، قفز وجاذبية، ومحاولة منع الحركة على المنحدرات الحادة.
- تحكم بلوحة المفاتيح وعصا لمس افتراضية وزر قفز.
- تكييف كثافة البكسل وحجم خريطة الظلال بحسب عرض الشاشة.

## التشغيل

افتح `index.html` في متصفح حديث مع اتصال بالإنترنت. يحتاج المتصفح إلى WebGL، ويحمّل Three.js r128 من:

`https://cdnjs.cloudflare.com/ajax/libs/three.js/r128/three.min.js`

أفضل تجربة على الهاتف عند تدويره أفقياً. زر البدء يحاول تفعيل ملء الشاشة وقفل الاتجاه الأفقي، لكن دعم هذه الميزات يختلف بين المتصفحات.

## التحكم

- الكمبيوتر: `W A S D` أو الأسهم للحركة، و`Space` للقفز.
- الهاتف: العصا الافتراضية للحركة، والزر ↑ للقفز.
- اسحب على مساحة العالم لتدوير الكاميرا.

## النشر على GitHub Pages

1. أنشئ مستودع GitHub جديداً وارفع محتويات هذا المجلد إلى الفرع `main`.
2. من إعدادات المستودع افتح **Settings → Pages** واختر **GitHub Actions** كمصدر للنشر.
3. سير العمل في `.github/workflows/pages.yml` سينشر الصفحة تلقائياً عند كل دفع إلى `main`.

## حدود هذه المرحلة

هذه ليست اللعبة الكاملة بعد. لا يوجد حتى الآن مولّد الكواكب الـ150 مليوناً، أو ماء وأنهار، أو نباتات، أو معادن، أو مسدس، أو مركبة فضائية، أو حفظ للتقدم. هذه الأنظمة مؤجلة للمراحل التالية.
