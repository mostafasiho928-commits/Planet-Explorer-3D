# مَدار — مستكشف الكواكب (المرحلة الثالثة)

لعبة استكشاف ثلاثية الأبعاد تعمل في المتصفح، مبنية على Three.js r128. المشروع حالياً صفحة HTML واحدة مع ملفات تعريف التطبيق، ولا يحتاج إلى Node.js أو خطوة بناء.

## ما أُنجز

### المرحلة الأولى — نواة الاستكشاف
- مشهد ثلاثي الأبعاد ورائد فضاء متحرك.
- حركة وقفز وجاذبية وكاميرا منظور شخص ثالث.
- عصا لمس للهاتف وأزرار لوحة المفاتيح.

### المرحلة الثانية — مولّد الكواكب
- مجال من **150,000,000 كوكب** بأرقام من 1 إلى 150,000,000.
- توليد حتمي لاسم الكوكب وبيئته ومناخه وحرارته وجاذبيته وطول يومه وخصائصه.
- ثمانية أنماط بيئية، مع اختلاف فعلي في ألوان السطح وارتفاعاته.
- اختيار كوكب برقمه أو اكتشاف كوكب عشوائي، مع معاينة الخصائص وحفظ آخر كوكب تمت زيارته.

### المرحلة الثالثة — العوالم الكروية
- استبدال الأرض المستوية بكوكب كروي ثلاثي الأبعاد.
- توليد التضاريس على سطح الكرة باستخدام ضوضاء إجرائية ثلاثية الأبعاد متصلة مكانياً، لتفادي فاصل خط الطول.
- تلوين السطح حسب الارتفاع والانحدار والثلوج والصخور.
- محيط كروي على الكواكب التي تتضمن مياه سطحية، مع مستوى بحر يختلف بحسب الكوكب.
- طبقة غلاف جوي شفافة يتغير لونها وسمكها وفق خصائص العالم.
- حركة اللاعب على سطح منحني باستخدام مسارات كروية، مع توجيه جسم رائد الفضاء والكاميرا وفق اتجاه الجاذبية المحلي.
- قفز وجاذبية خاصة بكل كوكب، محسوبة عمودياً على سطحه.

## الاتجاه الأفقي على الهاتف
- أزيلت شاشة «أدر هاتفك» التي كانت تحجب اللعبة عند فشل قفل الاتجاه.
- عند بدء اللعب، تطلب الصفحة ملء الشاشة ثم تحاول قفل الاتجاه على الوضع الأفقي.
- يتضمن المشروع ملف `manifest.webmanifest` بإعداد `orientation: landscape`. على Android، للحصول على قفل أكثر ثباتاً، انشر اللعبة على HTTPS عبر GitHub Pages ثم اختر من Chrome: **تثبيت التطبيق** أو **إضافة إلى الشاشة الرئيسية**، وافتح اللعبة من الأيقونة.
- قد لا يسمح المتصفح بقفل الاتجاه عند فتح ملف HTML محلياً أو داخل تبويب عادي؛ يعتمد ذلك على المتصفح وطريقة التشغيل.

## التشغيل
افتح `index.html` في متصفح حديث مع اتصال بالإنترنت. يحتاج المتصفح إلى WebGL، ويحمّل Three.js r128 من cdnjs.

## التحكم
- الكمبيوتر: `W A S D` أو الأسهم للحركة، و`Space` للقفز.
- الهاتف: العصا الافتراضية للحركة، والزر ↑ للقفز.
- اسحب على مساحة العالم لتدوير الكاميرا.
- زر **اختيار كوكب** يفتح بوابة الكواكب.

## ما لم يُنفذ بعد
النظام الحالي ينشئ كرة كوكبية بسطح إجرائي ومحيط وغلاف جوي. لم تُنفذ بعد النباتات والأشجار، والمعادن والكهوف، والطقس المتحرك، والأقمار والحلقات، أو المركبات الفضائية والهبوط والإقلاع. كذلك لا توجد بعد منظومة موارد أو أدوات أو مهام.
 
## النشر على GitHub Pages
من إعدادات المستودع اختر **Settings → Pages → Build and deployment → Source: GitHub Actions**. يحتوي المشروع سير عمل للنشر عند الدفع إلى الفرع `main`.
