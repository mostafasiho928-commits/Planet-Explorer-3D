# مَدار — مستكشف الكواكب (المرحلة السادسة التجريبية)

لعبة استكشاف ثلاثية الأبعاد للمتصفح، مبنية على Three.js r128. يعمل المشروع من صفحة HTML مع ملف تعريف PWA وأيقونة، ولا يحتاج إلى Node.js أو خطوة بناء.

## المراحل المنجزة

### المرحلة الأولى — نواة الاستكشاف
- مشهد ثلاثي الأبعاد ورائد فضاء متحرك.
- حركة وقفز وجاذبية وكاميرا منظور شخص ثالث.
- عصا لمس للهاتف وأزرار لوحة المفاتيح.

### المرحلة الثانية — مولّد الكواكب
- 150,000,000 كوكب مرقّم.
- توليد حتمي لاسم كل كوكب وبيئته ومناخه وحرارته وجاذبيته وطول يومه وخصائصه.
- ثمانية أنماط بيئية مختلفة.
- بوابة لاختيار كوكب برقم أو اكتشاف كوكب عشوائي.

### المرحلة الثالثة — العوالم الكروية
- كوكب كروي بنصف قطر 12,000 متر وقطر 24 كيلومتراً داخل مقياس اللعبة.
- قارات ومحيطات وسواحل، مع حركة اللاعب على سطح كروي وجاذبية وقفز محليين.
- تضاريس إجرائية متعددة المقاييس بدل تضاريس موحّدة الارتفاع.

### المرحلة الرابعة — الأنظمة البيئية والموارد
- أشجار متباعدة، أعشاب وصخور موزّعة على مساحة استكشاف أوسع.
- كتل غيوم متعددة الأجزاء تتحرك ببطء في الأفق.
- بلورات مضيئة قابلة للمسح والجمع، ومؤشر اتجاه ومسافة، ومخزون للعينات.

### المرحلة الخامسة — الجيولوجيا والطقس والتحكم
- سلاسل جبلية وهضاب ووديان مولدة إجرائياً، مع إبراز ارتفاع الجبال والمنحدرات والثلوج بالألوان والظلال.
- نصف قطر العالم 12 كيلومتراً، مع شبكة تصادم أرضية تستخرج موضع اللاعب من المثلثات الفعلية للمجسم، لتقليل الغوص داخل الهضاب.
- طقس بصري يتغير حسب الكوكب: مطر أو ثلج أو غبار أو صفاء، وسحب متعددة الأجزاء قريبة من مجال اللعب.
- عصا لمس مصححة الاتجاه، وكاميرا مستقلة عن ارتفاع المدار تسمح بالنظر إلى الأفق والسماء، مع تحريك يمين/يسار طبيعي وتقريب أوسع.
- شخصية أكبر وسرعة مشي وركض أعلى.

### المرحلة السادسة — الاستكشاف المتقدم والبقاء
- صخور خام قابلة للتعدين بثلاث ضربات، وعدّاد خام، وأداة تعدين مرئية في يد رائد الفضاء مع حركة ضربة.
- مدخل كهف وقاعة داخلية مضاءة ببلورات، مع زر دخول/خروج ونظام استهلاك الأكسجين وتجديده خارج الكهف.
- عربة استكشاف رباعية العجلات يمكن الصعود إليها وقيادتها بسرعة أعلى ثم الترجل منها.
- مكوك هبوط صغير يمكن الصعود إليه والإقلاع والهبوط الآلي، مع وقود ينفد أثناء الطيران ويُعاد شحنه عند التوقف خارج المكوك.
- قمر بعيد ذو حلقات كمعلم بصري في السماء.
- مهمة مترابطة: جمع خمس بلورات، استخراج ثلاث عينات خام، ثم دخول الكهف لإكمال مهمة الكوكب.

## جودة الرسوميات والأداء
- دقة سطح الكوكب 512×256 قطاعاً في الإعداد العادي و320×160 للأجهزة الأضعف.
- تفعيل الظلال على الهاتف والكمبيوتر؛ دقة خريطة الظلال 1024 للهاتف و2048 للأجهزة المكتبية.
- استخدام تنعيم الحواف ورفع حد دقة الرسم على الهواتف المتوسطة.
- إنشاء التضاريس والموارد على دفعات للسماح للمتصفح بتحديث الواجهة أثناء التحميل.

## الاتجاه الأفقي والهاتف
- تطلب اللعبة ملء الشاشة وتحاول قفل الاتجاه أفقياً عند الضغط على «ابدأ».
- ملف manifest.webmanifest يحدد orientation: landscape وdisplay: fullscreen.
- فتح index.html من ملف ZIP لا يفعّل إعدادات PWA. لتجربة قفل الاتجاه الحقيقي، افتح نسخة GitHub Pages عبر HTTPS، ثم من قائمة Chrome اختر «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية» وافتح اللعبة من أيقونتها.

## التحكم
- الكمبيوتر: W A S D أو الأسهم للحركة، Shift للركض، Space للقفز أو تشغيل الإقلاع/الهبوط أثناء قيادة المكوك، E للبحث، F لجمع، G للتعدين، C لدخول/مغادرة الكهف، V لقيادة العربة، وB للمكوك. اسحب بالفأرة يميناً لتدوير الكاميرا يميناً، واسحب للأعلى للنظر إلى السماء، واستخدم عجلة الفأرة للتقريب.
- الهاتف: العصا اليسرى للحركة بالاتجاه نفسه، اسحب في النصف الأيمن لتدوير الكاميرا، اسحب للأعلى لرؤية السماء، وقرّب أو أبعد إصبعين للتحكم بمسافة الكاميرا. الأزرار التفاعلية تظهر قرب البلورات والصخور والكهف والعربة والمكوك. زر الركض يعمل بالضغط المستمر، وزر ↻ يعيد الكاميرا.
- مهمة الكوكب: اجمع خمس بلورات، واستخرج ثلاث عينات خام، ثم ادخل الكهف.
- زر «اختيار كوكب» يتيح الانتقال إلى كوكب آخر.

## حدود النسخة الحالية
هذه مرحلة لعب تجريبية وليست محاكاة فضائية كاملة. الكهف مساحة لعب مضافة فوق سطح التضاريس وليست حفراً في شبكة الكوكب نفسها. طيران المكوك قفز عمودي مضبوط داخل مجال الجاذبية وليس مداراً فضائياً أو سفراً بين الكواكب. القمر ذو الحلقات عنصر مرئي في السماء ولا يحسب مدارات جاذبية حقيقية. الطقس مؤثرات بصرية مبسطة، وليس نموذجاً مناخياً. لا يوجد قتال أو أسلحة؛ أُضيفت أداة تعدين لأن التعدين له هدف فعلي داخل النسخة. لا تزال الأنظمة قابلة للتوسعة إلى كهوف محفورة، ومدارات، ووقود/أكسجين أكثر تفصيلاً، ومهام متعددة.

## النشر
المستودع يستخدم GitHub Actions لنشر الموقع على GitHub Pages عند الدفع إلى الفرع main. يجب ضبط Settings → Pages → Build and deployment → Source: GitHub Actions.
