# مَدار — مستكشف الكواكب (المرحلة الثانية)

لعبة استكشاف ثلاثية الأبعاد تعمل في المتصفح، مبنية على Three.js r128، ومهيأة للحاسوب والهاتف. المشروع حالياً في ملف `index.html` واحد ولا يحتاج إلى Node.js أو خطوة بناء.

## ما أُنجز

### المرحلة الأولى — نواة الاستكشاف
- مشهد ثلاثي الأبعاد مع سماء وإضاءة اتجاهية وظلال.
- تضاريس إجرائية مقسمة إلى قطع (Chunks) تُحمّل حول اللاعب.
- رائد فضاء بحركة أطراف، وكاميرا منظور شخص ثالث.
- حركة وقفز وجاذبية، مع عصا لمس للهاتف وأزرار لوحة المفاتيح.

### المرحلة الثانية — مولّد الكواكب
- مجال من **150,000,000 كوكب** بأرقام من 1 إلى 150,000,000.
- كل رقم ينتج بذرة رقمية ثابتة وفريدة ضمن هذا المجال، باستخدام تحويل قابل للعكس على 32 بت؛ لا تُخزّن نسخ الكواكب مسبقاً.
- توليد حتمي لاسم الكوكب وبيئته ومناخه ودرجة حرارته والجاذبية وطول اليوم وكثافة الغلاف الجوي وخصائص التضاريس.
- ثمانية أنماط بيئية أولية، لكل منها لوحة ألوان وإضاءة وضباب وخصائص تضاريس مختلفة.
- اختلاف التضاريس فعلياً بحسب بذرة الكوكب، وليس تغيير اسم أو لون الواجهة فقط.
- بوابة لاختيار رقم كوكب محدد أو الانتقال إلى كوكب عشوائي، مع معاينة خصائصه قبل السفر.
- الجاذبية الخاصة بالكوكب تؤثر في تسارع السقوط وحركة القفز.
- حفظ آخر كوكب تمت زيارته محلياً في المتصفح، ليستعيده اللاعب عند العودة.

## ما لم يُنفذ بعد

المولّد الحالي ينشئ هوية الكوكب وخصائصه وتضاريسه الإجرائية عند الطلب، بينما منطقة اللعب ما زالت أرضاً إجرائية ممتدة مبنية من قطع. لم تُنفّذ بعد كروية الكوكب الفعلية وانحناء الأفق، أو المحيطات والأنهار، أو النباتات، أو المعادن والأسلحة، أو المركبة الفضائية. هذه أنظمة لاحقة وليست ممثلة حالياً على أنها مكتملة.

## التشغيل

افتح `index.html` في متصفح حديث مع اتصال بالإنترنت. يحتاج المتصفح إلى WebGL، ويحمّل Three.js r128 من:

`https://cdnjs.cloudflare.com/ajax/libs/three.js/r128/three.min.js`

أفضل تجربة على الهاتف عند تدويره أفقياً. دعم ملء الشاشة وقفل الاتجاه الأفقي يختلف بين المتصفحات.

## التحكم

- الكمبيوتر: `W A S D` أو الأسهم للحركة، و`Space` للقفز.
- الهاتف: العصا الافتراضية للحركة، والزر ↑ للقفز.
- اسحب على مساحة العالم لتدوير الكاميرا.
- زر **اختيار كوكب** يفتح بوابة الكواكب؛ أدخل رقماً ثم انتقل، أو اطلب كوكباً عشوائياً.

## النشر على GitHub Pages

المستودع يحتوي سير عمل في `.github/workflows/pages.yml` ينشر الصفحة عند الدفع إلى الفرع `main`. من إعدادات المستودع يجب اختيار **Settings → Pages → GitHub Actions** كمصدر للنشر.
